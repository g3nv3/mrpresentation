YandexHelmetRoutePresenter

Класс отвечает за последнюю милю Yandex-навигации: берет географические точки маршрута, переводит их в Unity-координаты вокруг игрока или шлема, упрощает линию и передает ее в общий визуальный компонент RoutePathView.

MonoBehaviour IYandexRoutePresenter GeoCoordinate -> Vector3 RoutePathView facade
Assets/Project/Scripts/Navigation/Yandex/Presentation/YandexHelmetRoutePresenter.cs

Роль В Системе

1

Route client

Запрашивает маршрут у Yandex Maps API или OpenRouteService.

2

Navigator

YandexHelmetNavigator хранит текущую координату и вызывает presenter.

3

Presenter

Проецирует GeoCoordinate в локальные точки маршрута.

4

RoutePathView

Получает готовые world-space точки и управляет линией, тенью и marker.

5

LineRenderer

Показывает маршрут в сцене шлема Pico.

Что класс делает

Переводит широту и долготу в смещения в метрах, нормализует начало маршрута в ноль, применяет масштаб, offset и поворот, затем рисует линию.

Чего класс не делает

Не отправляет HTTP-запросы, не парсит JSON, не строит NavMesh и не выбирает destination. Это делает YandexHelmetNavigator и route clients.

Главная зависимость

RoutePathView. Если он не назначен в Inspector, presenter пробует найти его через GetComponent<RoutePathView>().

Основной Алгоритм

Как строятся локальные точки

Метод берет список GeoCoordinate, выбирает origin: либо явно заданный через SetGeographicOrigin, либо первую точку маршрута. Каждая точка переводится в east/north offset через GeoCoordinateUtility.GetMetersOffset, после чего east становится Unity X, north становится Unity Z.

Затем из всех точек вычитается первая рассчитанная точка. Поэтому маршрут визуально начинается от routeOffset, а не от абсолютного положения географического origin. 

origin = _geographicOrigin ?? routePoints[0]
metersOffset = GeoCoordinateUtility.GetMetersOffset(origin, point)
localPoint = new Vector3(east * scale, 0, north * scale)

visualStartOffset = sourceLocalRoutePoints[0]
sourceLocalRoutePoints[i] -= visualStartOffset

Как точки попадают в сцену

DrawLocalRoute берет anchor: playerTransform, если он назначен, иначе transform самого компонента. Дальше вычисляется rotation и origin. Каждая локальная точка становится world-space точкой: origin + rotation * localPoint.

После этого массив передается в RoutePathView.ShowWithRelativeShadow. Именно поэтому Yandex-маршрут переиспользует общий renderer, тень и endpoint-маркер. 

anchor = playerTransform ?? transform
rotation = GetRouteRotation(anchor)
origin = GetRouteOrigin(anchor, rotation)

worldPoint = origin + rotation * localPoint
pathView.ShowWithRelativeShadow(worldRoutePoints, ...)

Зачем нужен geographicNorthYawDegrees

Географические точки приходят в системе east/north, где north соответствует направлению на север. В Unity мировая ось +Z не обязана совпадать с реальным севером. Поле geographicNorthYawDegrees задает поворот географического севера относительно Unity +Z.

TryAlignGeographicNorthToHeading вычисляет этот угол из текущего yaw игрока и известного heading. После первого успешного course alignment повторные вызовы TryAlignGeographicNorthToCourse больше не меняют ориентацию. 

geographicNorthYawDegrees =
    Mathf.DeltaAngle(0f, playerYaw - headingDegrees)

GetGeographicNorthRotation() =
    Quaternion.Euler(0, geographicNorthYawDegrees, 0)

Что очищается при выключении

DisableRoute сбрасывает текущий route, локальные и world-space списки, флаги endpoint и truncation, затем скрывает RoutePathView. Это полный визуальный reset presenter-а. 

_currentRoute = null
_localRoutePoints.Clear()
_visibleSourceLocalRoutePoints.Clear()
_worldRoutePoints.Clear()
_isVisibleRouteTruncated = false
_hasWorldRouteEndpoint = false
pathView?.Hide()

Поля Inspector

Поле Назначение Практический смысл
playerTransform Anchor, относительно которого показывается маршрут. Обычно XR rig, camera или объект головы. Если пусто, используется transform presenter-а.
routeOffset Локальный сдвиг начала линии от игрока. По умолчанию линия начинается ниже и впереди игрока: (0, -0.35, 1.2).
followPlayerTransform Пересчитывает world-space точки в LateUpdate. Нужно, если маршрут должен оставаться привязанным к движущемуся игроку.
rotateWithPlayer Поворачивает маршрут вместе с anchor. Если выключено, линия ориентируется по geographicNorthYawDegrees, а не по голове.
yawOnlyRotation Берет только поворот по Y. Сохраняет линию горизонтальной и игнорирует pitch/roll шлема.
geographicNorthYawDegrees Поворот реального севера в Unity. Калибрует географический маршрут относительно сцены.
metersToUnityScale Масштаб перевода метров в Unity units. Для Pico spatial mesh обычно 1.
maxRenderedPoints Лимит точек, передаваемых renderer-у. Защищает LineRenderer и сцену от слишком плотной полилинии.
drawRoutePrefixWhenPointBudgetExceeded При превышении лимита рисует только начало маршрута. Если выключить, класс пытается упростить весь маршрут до лимита.
simplificationToleranceMeters Допуск упрощения линии. Чем выше значение, тем меньше точек и грубее форма маршрута.
pathView Визуальный фасад линии маршрута. Управляет RouteLineRendererView, тенью и endpoint-маркером.
usePathViewPointProjector Разрешает RoutePathView проецировать точки. Для Yandex обычно выключено, чтобы линия не ложилась на MRMesh.
usePathViewPointOffset Разрешает offset внутри RoutePathView. Для Yandex обычно выключено, чтобы общий NavMesh-offset не поднял линию к голове.
shadowOffsetRelativeToRoute Смещение тени относительно итоговой линии. Позволяет получить подложку ниже маршрута без повторной проекции.

Публичный API

TryShowRoute(YandexRouteData) и TryShowRoute(IReadOnlyList<GeoCoordinate>) строят локальную линию и пытаются ее отрисовать. Возвращают false, если данных мало или нет renderer-а.

ShowRoute и BuildPath являются удобными обертками над TryShowRoute.

SetGeographicOrigin фиксирует origin для преобразования координат. Navigator вызывает его по первой точке полученного маршрута.

IsPlayerWithinEndpointDistance проверяет расстояние игрока до endpoint в плоскости X/Z и используется navigator-ом для завершения маршрута.

Внутреннее Состояние

_sourceLocalRoutePoints хранит все исходные локальные точки после гео-проекции.

_visibleSourceLocalRoutePoints используется только когда включен режим рисования prefix при превышении лимита.

_localRoutePoints содержит уже упрощенную полилинию, готовую к повороту и размещению около anchor.

_worldRoutePoints содержит итоговые точки для RoutePathView.

Упрощение И Лимиты

Алгоритм

SimplifyRoute реализует вариант Ramer-Douglas-Peucker: сохраняет первую и последнюю точку, ищет самую далекую точку от сегмента, рекурсивно делит диапазоны через stack и оставляет только точки, отклонение которых больше tolerance.

Поведение при слишком длинном маршруте

Если drawRoutePrefixWhenPointBudgetExceeded включен и исходных точек больше maxRenderedPoints, рисуется только начало маршрута. В этом случае endpoint-маркер скрывается, потому что видимая последняя точка уже не является настоящим финишем.

Важная деталь: даже если визуальная линия обрезана, _localRouteEndpoint хранит настоящий endpoint. Поэтому IsPlayerWithinEndpointDistance сравнивает игрока с реальным финишем, а не с концом видимого prefix.

Поворот И Origin

rotateWithPlayer = false

Origin сдвигается по yaw игрока, но сама линия повернута по географическому северу.

rotateWithPlayer = true, yaw only

Origin и линия используют только yaw anchor, поэтому линия остается горизонтальной.

yawOnlyRotation = false

Используется полный anchor.rotation и anchor.TransformPoint(routeOffset).

Минимальный Сценарий Использования

var presenter = GetComponent<YandexHelmetRoutePresenter>();

presenter.SetPlayerTransform(xrCameraTransform);
presenter.SetRouteOffset(new Vector3(0f, -0.35f, 1.2f));
presenter.TryAlignGeographicNorthToHeading(deviceHeading);

presenter.TryShowRoute(routeData);
