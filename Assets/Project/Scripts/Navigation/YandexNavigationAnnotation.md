# Программное средство построения и отображения маршрутов Яндекс.Карт в пространстве смешанной реальности

## Аннотация

Программное средство представляет собой систему, предназначенную для построения и отображения маршрута в пространстве смешанной реальности с использованием шлема виртуальной реальности Pico 4 Ultra и сервисов Яндекс.Карт. Программное средство получает на вход начальную и конечную географические координаты, формирует запрос к Yandex Route API и получает маршрут, содержащий набор географических точек, длину участков и расчетное время движения.

После получения маршрута программное средство преобразует географические координаты в локальные координаты Unity и отображает маршрут перед пользователем в пространстве шлема с помощью графической линии. Маршрут может следовать за положением и поворотом пользователя, что позволяет использовать его как навигационную подсказку в режиме смешанной реальности.

Дополнительно программное средство может выполнять проверку объектов окружающего пространства. Для этого используется raycast по пространственной сетке Pico spatial mesh, точка попадания переводится в географические координаты относительно заданного гео-якоря, после чего через Yandex Geocoder API определяется, является ли найденный объект зданием, и возвращается его адресная информация.
